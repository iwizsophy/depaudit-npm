# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project aims to follow Semantic Versioning.

## [1.0.0] - 2026-04-01

### Added

- Initial Go implementation of the npm dependency scanner
- Cross-platform support for Windows, Linux, and macOS
- Configurable target package list via `targets.txt` or `--targets-file`
- GitHub Actions CI and tag-based release workflow
- Release archives for Windows, Linux, and macOS
- Public OSS documentation, contribution guidance, and security policy
